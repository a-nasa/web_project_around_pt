# Around The U.S.

Página interativa onde os usuários podem adicionar, remover e curtir fotos de lugares incríveis ao redor dos Estados Unidos.

## Sobre o projeto

Este projeto faz parte do Sprint 8 (Métodos em JavaScript e manipulação do DOM). A estrutura HTML e os estilos CSS já estavam prontos, e o objetivo é adicionar interatividade com JavaScript.

### Etapa 1: Seu próprio conjunto de dados

- Criação do arquivo `scripts/index.js`, vinculado ao HTML.
- Criação do array `initialCards`, com seis objetos contendo `name` e `link`.
- Uso do método `forEach()` para percorrer o array e exibir o nome de cada cartão no console.

## Tecnologias utilizadas

- HTML5
- CSS3 (metodologia BEM)
- JavaScript
